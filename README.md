Wi-Fi Password Security Auditor

1. Project Title

Wi-Fi Password Security Auditor Using Python

2. Aim

To analyze a Wi-Fi password and identify basic security weaknesses using Python.

3. Description

The Wi-Fi Password Security Auditor is a Python program that checks a password's length, character types, common patterns, and repeated characters. It provides a basic assessment of password security.

4. Features

- Checks password length.
- Identifies uppercase and lowercase letters.
- Checks numbers and special characters.
- Detects common password patterns.
- Identifies repeated characters.
- Displays a basic security assessment.

5. Requirements

- Python 3
- Notepad or VS Code

6. How to Run

1. Save the program as "wifi_password_auditor.py".
2. Open Command Prompt or the VS Code terminal.
3. Run the following command:

python wifi_password_auditor.py

4. Enter a Wi-Fi password when prompted.

7. Sample Output

===== WI-FI PASSWORD SECURITY AUDITOR =====

Enter Wi-Fi password: Home@12345

Password Length: Valid
Character Variety: Good
Common Pattern Check: Warning

Security Assessment: Needs Improvement

Note: This is an illustrative output. The actual result depends on the program's rules and the password entered.

8. Applications

- Basic Wi-Fi password security awareness
- Identifying weak password patterns
- Learning Python string operations and conditions

9. Limitation

This program only analyzes the password entered by the user. It does not connect to a Wi-Fi network or test the actual network's security.

10. Conclusion

The Wi-Fi Password Security Auditor demonstrates how Python can identify basic password weaknesses and encourage the use of stronger passwords.
